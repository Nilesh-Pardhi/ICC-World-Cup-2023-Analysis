# 🏏 ICC Men's Cricket World Cup 2023 – Data Analysis

## 📌 Project Overview

This project focuses on analyzing the ICC Men's Cricket World Cup 2023 data to uncover insights into team performance, match results, toss decisions, and tournament statistics.

Using Python and data analysis libraries, this project explores cricket datasets, performs data cleaning, conducts Exploratory Data Analysis (EDA), and visualizes key findings through charts.

## 🎯 Project Objectives

* Analyze match results and team performance.
* Identify teams with the highest number of wins.
* Understand the distribution of toss decisions.
* Investigate how often the toss-winning team also won the match.
* Analyze match-winning margins based on runs and wickets.
* Explore venues, cities, and Player of the Match awards.
* Present insights through clear and informative visualizations.

## 📂 Datasets

This project uses three datasets:

1. **Matches Dataset** – Match details, participating teams, toss decisions, winners, venues, and Player of the Match.
2. **Deliveries Dataset** – Ball-by-ball information, runs, extras, innings, and wicket details.
3. **Points Table Dataset** – Team rankings, matches played, wins, losses, points, and net run rate.

## 🔍 Analysis Performed

### 1. Data Cleaning

* Checked for missing values and duplicate records.
* Standardized column names and text values.
* Converted columns to appropriate data types.

### 2. Exploratory Data Analysis (EDA)

* Which teams recorded the highest number of wins?
* What was the distribution of toss decisions between batting first and fielding first?
* How often did the toss-winning team also win the match?
* Which teams won matches after winning the toss?
* Which venues hosted the most matches?
* Which players received the most Player of the Match awards?
* Which matches had the largest winning margins by runs and wickets?

### 3. Data Visualization

Created charts to compare team wins, toss decisions, match outcomes, and other tournament statistics.

## 📊 Key Insights

The analysis aims to identify:

* Overall team performance throughout the tournament.
* Patterns in toss decisions.
* The relationship between winning the toss and winning the match.
* Standout teams, players, and match results.
